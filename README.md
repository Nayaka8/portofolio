# 🚀 Personal Portfolio Website

Website portofolio pribadi yang dirancang untuk menampilkan proyek *full-stack web development*, *interactive dashboards*, serta pengalaman teknis lainnya. Built with **Next.js**, **React**, **TypeScript**, and **Tailwind CSS**.

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide Icons / Custom SVG Components
- **Deployment:** Vercel

## 📌 Features

- 📱 Responsive Design (Mobile & Desktop Friendly)
- ⚡ Fast Performance & SEO Optimized
- 🎨 Clean & Modern UI/UX
- 📁 Dynamic Resume Data Integration
